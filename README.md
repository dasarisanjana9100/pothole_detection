# Pothole and Road Damage Detection

## Project Description
This project detects potholes and road damage
using a CNN-based YOLOv8 object detection model.

## Technology Used
- Python
- Google Colab
- YOLOv8
- OpenCV
- Deep Learning
- Computer Vision

## Dataset
The project uses a pothole and road damage
image dataset.

## Implementation
1. Dataset preparation
2. Model training using YOLOv8n
3. Image detection
4. Video processing
5. Detection result visualization
   
streamlit
ultralytics
opencv-python-headless
pillow
numpy
## Output
The trained model detects potholes and
road damage in images and videos.
